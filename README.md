# Suivi des temps de Sarah

- `index.html` : le site (identique à celui de Luka). Pas besoin d'y toucher.
- `donnees.js` : les temps saisis à la main.
- `donnees-ffn.js` : courses récupérées automatiquement sur la fiche FFN de Sarah. Ne pas le modifier.

## Mettre à jour depuis la FFN

Onglet **Actions** > « Mise à jour depuis la FFN » > **Run workflow**.
Si l'Action échoue avec une erreur de droits : **Settings > Actions > General > Workflow permissions**, cocher « Read and write permissions ».
